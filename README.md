# Agentic Fieldbook

> An operating methodology for autonomous agents.

Agentic Fieldbook is an opinionated, installable methodology bundle for planning, routing, calibrating, reviewing, verifying, and handing off autonomous agent work on Hermes Agent.

**Status:** Planning complete; implementation not yet started.

## Scope

This project is a methodology and skills layer, not an agent runtime, operating system, orchestration engine, or Hermes core feature.
